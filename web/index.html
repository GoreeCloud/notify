Connection settings

Connect to your own ntfy instance. A same-origin proxy at /api/ntfy is recommended for privately hosted deployments.

Remote servers must use HTTPS and allow browser cross-origin requests. The browser only connects to the endpoint you configure.

Tokens stay in memory only and are erased on refresh. Leave blank to keep the current session token.
